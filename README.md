# ⛽ তামার পাম্প - ফুয়েল রেশনিং সিস্টেম | Tamar Pump - Fuel Rationing System

একটি আধুনিক, দ্বিভাষিক (বাংলা ও ইংরেজি) জ্বালানি বিতরণ ও রেশনিং ব্যবস্থাপনা ওয়েব অ্যাপ্লিকেশন।
A modern, bilingual (Bengali & English) fuel dispensing and rationing management web application.

---

## 🌟 বৈশিষ্ট্যসমূহ (Features)

- 🌐 **দ্বিভাষিক সমর্থন (Bilingual Support)**: এক ক্লিকেই বাংলা ও ইংরেজির মধ্যে ভাষা পরিবর্তনের সুবিধা (1-Click Bangla/English Language Switcher with persisted settings).
- 📊 **কেন্দ্রীয় ড্যাশবোর্ড (Central Dashboard)**: মোট রেজিস্টার্ড গাড়ি, মোট লেনদেন, মোট জ্বালানি বিতরণ এবং বর্তমানে অপেক্ষমাণ (ব্লক) গাড়ির রিয়েল-টাইম পরিসংখ্যান।
- 🔍 **যোগ্যতা যাচাই (Eligibility Check)**: গাড়ির নম্বর অথবা ড্রাইভিং লাইসেন্স নম্বর দিয়ে তাত্ক্ষণিক যাচাইকরণ এবং অবশিষ্ট অপেক্ষার দিন ও পরবর্তী অনুমোদিত তারিখ প্রদর্শন।
- ⛽ **৩-ধাপে তেল বিক্রি (3-Step Fuel Dispensing)**: গাড়ি যাচাইকরণ ➔ জ্বালানির পরিমাণ নির্ধারণ (কুইক প্রিসেট সহ) ও কর্মী নির্বাচন ➔ রসিদ প্রিন্ট বা সংরক্ষণ।
- ⏱️ **রেশনিং কুলডাউন নিয়ম (Cooldown Rules)**:
  - ১–২ লিটার: ২ দিন অপেক্ষা
  - ৩–৪ লিটার: ৩ দিন অপেক্ষা
  - ৫–৭ লিটার: ৫ দিন অপেক্ষা
  - ৮–৯ লিটার: ৭ দিন অপেক্ষা
  - ১০–১৪ লিটার: ১০ দিন অপেক্ষা
  - ১৫+ লিটার: ১২ দিন অপেক্ষা
- 📝 **গাড়ি রেজিস্ট্রেশন (Vehicle Registration)**: মালিকের নাম, ড্রাইভিং লাইসেন্স ও গাড়ির ধরন (বাইক/কার) দিয়ে অনন্য রেজিস্ট্রেশন।
- 🚗 **নিবন্ধিত গাড়ির তালিকা (Vehicles List)**: বাইক/কার ফিল্টার, লাইভ সার্চ, ডিরেক্ট সেল অ্যাকশন এবং এক ক্লিকে **CSV এক্সপোর্ট**।
- 📋 **লেনদেন ইতিহাস (Transaction Audit Log)**: সকল, ব্লক এবং মুক্ত ফিল্টারিং, অনুসন্ধান এবং **CSV এক্সপোর্ট**।
- 💾 **হাইব্রিড অফলাইন/অনলাইন ডাটাবেজ (Hybrid Offline/Online Storage)**: ব্যাকএন্ড এপিআই থাকলে স্বয়ংক্রিয় সিঙ্ক, ব্যাকএন্ড না থাকলেও ব্রাউজার লোকাল স্টোরেজে সম্পূর্ণ কার্যকর ডেমো ডেটা সহ নিরবচ্ছিন্নভাবে চালিত।
- 🎨 **প্রিমিয়াম ইউজার ইন্টারফেস (Modern UI/UX)**: Lucide React আইকন, রেসপন্সিভ মোবাইল ড্রয়ার, টোস্ট নোটিফিকেশন, প্রিন্ট উপযোগী রসিদ।

## 🚀 টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend**: React 19, Vite 8, React Router 7
- **Styling**: Tailwind CSS v4 & Custom Design Tokens
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Typography**: Hind Siliguri (Bengali) + Inter (English) Google Fonts

## 💻 লোকাল সেটআপ ও রান করার নিয়ম (Getting Started)

1. রিপোজিটরি ক্লোন করুন বা ফোল্ডারে যান:
   ```bash
   cd "oil pump"
   ```

2. ডিপেন্ডেন্সি ইনস্টল করুন:
   ```bash
   npm install
   ```

3. ডেভেলপমেন্ট সার্ভার চালু করুন:
   ```bash
   npm run dev
   ```
   অ্যাপ্লিকেশনটি ব্রাউজারে `http://localhost:5173` এ চালু হবে।

4. প্রোডাকশন বিল্ড তৈরি করতে:
   ```bash
   npm run build
   ```
